# CueCast 0.10.0

First public installation release for Windows x64 and Raspberry Pi OS 64-bit Trixie ARM64.

## What's new

- Multiple independent tables in one application, with separate cameras, overlays, output quality, previews and streaming destinations.
- Start and stop each table independently. Switching tables does not stop broadcasts.
- Reuse a connected YouTube account when adding a table; each broadcast has its own title and output key.
- Per-table RTSP paths with one shared listener on port 8554.
- Protection against opening the same local camera twice or publishing two outputs with the same stream key.
- Original settings are preserved as the first table. Back up the entire data directory before upgrading.
- Smaller public Windows online installer; video tools are downloaded directly from their upstream distributors.

## Downloads

- **cuecast-windows-x64.zip** — Windows 10/11 x64. Extract and run `Install.cmd`. Internet is required during installation; video dependencies are downloaded automatically. The package is not digitally signed.
- **cuecast-raspberry-pi-arm64.deb** — Raspberry Pi OS Lite 64-bit / Debian 13 Trixie ARM64. Install with `sudo apt install ./cuecast-raspberry-pi-arm64.deb`. Dependencies come from your system repositories.
- **SHA256SUMS.txt** — compare checksums before installation if needed.

See [installation instructions](https://github.com/komo81/cuecast-downloads#readme). Stop broadcasts before updating. Keep local ports on a trusted network: the local interface does not have authentication.

## Verification and limitations

Application tests, browser UI checks and Windows bundled startup/media smoke tests pass. Online runtime preparation is tested before packaging. Real camera and multi-stream performance depends on your hardware and available encoder sessions; Raspberry Pi can keep using one table. Raspberry Pi package build tests are not a full clean-device installation test.

No passwords, stream keys, user configuration or sign-in tokens are included. Third-party license notices are included with the relevant runtime packages. Source build commit: `3058400a1cb21ca466caa39905be18a6c31eb811`.

## Česky

První veřejné vydání přidává více samostatných stolů. Každý má vlastní kameru, overlay, kvalitu a cíl vysílání. Původní nastavení se zachová. Windows: rozbalte ZIP a spusťte `Install.cmd`; instalátor potřebuje internet a stáhne video nástroje. Pi: stáhněte DEB a nainstalujte přes APT. Před aktualizací zastavte vysílání a zazálohujte celý adresář dat.
